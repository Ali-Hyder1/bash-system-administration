# 🐧 Bash System Administration Menu

A beginner-friendly Bash scripting project created to practice Linux commands, shell scripting, functions, loops, and user input.

## 📌 About the Project

The Bash System Administration Menu is a simple command-line program that provides users with a menu to perform basic system administration tasks.

This is one of my beginner projects, built to improve my Linux knowledge and Bash scripting skills.

## ✨ Features

- 🖥️ **System Information** — Displays system information.
- 💾 **Disk Usage** — Checks disk space usage.
- 🧠 **RAM Usage** — Displays memory usage.
- 📁 **Create a Directory** — Allows users to create a directory.
- 🔄 **Interactive Menu** — Lets users select options from a menu.
- 🚪 **Exit Option** — Allows users to exit the program.

## 🛠️ Technologies Used

- Linux
- Bash Shell Scripting
- Linux Command-Line Interface (CLI)

## ▶️ How to Run

**Step 1: Clone the Repository**

```bash
git clone https://github.com/Ali-Hyder1/bash-system-administration.git
```

**Step 2: Open the Project Directory**

```bash
cd bash-system-administration
```

**Step 3: Run the Script**

```bash
bash main.sh
```

**Note:** Replace `main.sh` with your Bash file's actual name if it is different.
